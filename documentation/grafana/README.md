# Grafana dashboard

`norppa_api_traffic.json` is a Grafana dashboard for Norppa logs.

## Importing

1. In Grafana, go to **Dashboards → New → Import**.
2. Upload `norppa_api_traffic.json` or copypaste the json into the box.
3. Click **Load**.
4. Click **Import**. Either overwrite the existing dashboard or create a new one.

## Modifying the dashboard

If you need to modify this dashboard, I recommend letting your 🤖 edit the json directly here in the repo, and then overwriting the Grafana dashboard. If you make changes through the Grafana UI and want them to persist, copy the contents of **Dashboard settings → JSON Model** and commit them here.
