# Custom voices

A voice is a `<name>.wav` file here, selected with `MANUAL_VOICE=<name>`. Without one, Chatterbox's built-in voice (`default`) is used.

The clip should be about 10 seconds of clean speech, with one speaker, no music and no background noise. Chatterbox clones the voice from this clip, and no training is needed.

Before adding someone's voice:

- Get their written consent for their voice to be used in public, AI-generated user manual videos.
- Next to the clip, add `<name>.md` saying who the speaker is, where and when the recording was made, and where the consent is kept.
